# SQL Questions (1–10)

### Q1. Display the names of all employees along with their department names.

```sql id="m8x2pk"
SELECT e.name, d.dept_name
FROM employees e
JOIN departments d
ON e.dept_id = d.dept_id;
```

### Q2. Find the department(s) that have no employees.

```sql id="u4v8rt"
SELECT d.dept_id, d.dept_name
FROM departments d
LEFT JOIN employees e
ON d.dept_id = e.dept_id
WHERE e.emp_id IS NULL;
```

### Q3. Find the highest salary in each department along with the department name.

```sql id="p7m1qw"

    d.dept_name,
    MAX(e.salary) AS highest_salary
FROM employees e
JOIN departments d
ON e.dept_id = d.dept_id
```

### Q26. Write a UDF to classify tenure: <3yrs='New', 3-5yrs='Mid', >5yrs='Veteran'. (Assume 2025)

```python id="a2s5df"
from pyspark.sql.functions import udf
from pyspark.sql.types import StringType

def classify_tenure(year):
    tenure = 2025 - year.year

    if tenure < 3:
        return "New"
    elif tenure <= 5:
        return "Mid"
    else:
        return "Veteran"

tenure_udf = udf(classify_tenure, StringType())

result = employees_df.withColumn(
    "tenure_category",
    tenure_udf(col("join_date"))
)

result.show()
```
